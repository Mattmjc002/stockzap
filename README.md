StockZap

Sistema web para gerenciamento e controle de estoque, desenvolvido como projeto acadêmico.

📋 Sobre o projeto

O StockZap é uma aplicação web desenvolvida para auxiliar no gerenciamento de produtos e estoque, buscando tornar o controle de informações mais simples, organizado e acessível.

O projeto está sendo desenvolvido utilizando tecnologias web e possui como objetivo principal criar uma interface intuitiva para gerenciamento de estoque.
